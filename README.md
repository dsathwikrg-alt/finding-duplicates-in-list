# finding-duplicates-in-list
Need to Find the Duplicate Elements in a Given List


# Algorithm is ::

# 1. Define a function that accepts list of elements
# 2. Pick each element at once and compare it with the rest of the elements in the list
# 3. Initialize counter variable
# 4. Increment the counter if found duplicate and add it to a second list
# 5. return the duplicates list and print at the end
# 6. Eg: [1,1,2,4,6,2]
# 7. list_size = 6
